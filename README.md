# SmartEdgeIO Systems Website

React + Vite + Tailwind CSS + Lucide React + Motion.

## Run in VS Code

Open this folder in VS Code, then open Terminal:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Deploy later

The project is prepared for static hosting such as GitHub Pages. The Vite `base` is set to `./` so the generated site can also be previewed from static hosting.

## Assets

Website images are under `public/images`.
The SmartEdgeIO logo is under `public/logo`.

This is the initial homepage foundation. Additional pages can be added under `src/pages/`.
